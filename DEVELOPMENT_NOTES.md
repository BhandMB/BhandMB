# Portfolio Profile Maintenance Checklist

Use this checklist when updating the public developer profile.

- Keep the headline aligned with Java and Spring Boot backend roles.
- Pin projects that demonstrate REST APIs, persistence, testing, and clear documentation.
- Keep repository descriptions concise and consistent with the actual implementation.
- Verify project links and setup instructions after profile edits.
- Remove outdated claims and describe only skills that can be discussed confidently in an interview.
- Refresh the profile when a meaningful feature, test suite, or deployment milestone is completed.

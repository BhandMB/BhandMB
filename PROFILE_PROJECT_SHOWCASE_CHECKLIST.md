# GitHub Profile Project Showcase Checklist

Use this checklist to keep featured projects useful to recruiters and engineering reviewers.

## Project selection
- [ ] Prioritize projects relevant to the target role.
- [ ] Keep the strongest backend project easy to find.
- [ ] Avoid presenting tutorial-only work as production experience.

## Evidence and clarity
- [ ] Explain the problem solved and the key implemented features.
- [ ] List the actual technology stack used.
- [ ] Provide reproducible setup and run instructions.
- [ ] Include real screenshots or a demo when available.
- [ ] State test coverage and build status accurately.
- [ ] Link to API documentation or architecture notes when useful.

## Maintenance
- [ ] Remove broken links and stale badges.
- [ ] Keep descriptions concise and interview-defensible.
- [ ] Update featured projects when substantial code improvements are completed.
- [ ] Never publish secrets, private data, or unsupported claims.

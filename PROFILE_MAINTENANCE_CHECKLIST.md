# GitHub Profile Repository Maintenance Checklist

Use this checklist when refreshing the public profile README and pinned projects.

- [ ] Keep the headline aligned with current skills and target roles.
- [ ] Feature the strongest Java and Spring Boot backend project prominently.
- [ ] Describe projects with accurate technologies and verifiable outcomes.
- [ ] Ensure repository links and demo links work.
- [ ] Keep setup instructions short and reproducible.
- [ ] Remove stale badges, broken images, and unsupported claims.
- [ ] Avoid publishing personal secrets, credentials, or private information.
- [ ] Check mobile readability and heading structure.
- [ ] Review pinned repositories for build instructions, tests, and useful READMEs.
- [ ] Revisit the profile after meaningful project improvements.

Prefer demonstrated features and measurable results over inflated skill lists.

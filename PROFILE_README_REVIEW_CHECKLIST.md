# GitHub Profile README Review Checklist

Use this checklist when reviewing the profile README for accuracy and clarity.

## Professional positioning
- [ ] The headline reflects current skills and target roles.
- [ ] Featured repositories are maintained, understandable, and relevant.
- [ ] Project descriptions explain the problem, stack, and implemented functionality.
- [ ] Learning goals are clearly distinguished from demonstrated experience.

## Repository links and evidence
- [ ] All links open the intended repository or profile.
- [ ] Pinned repositories have useful READMEs and setup instructions.
- [ ] Screenshots and demos are current and belong to the project.
- [ ] Build and test badges, if present, reflect real workflows.

## Quality and maintenance
- [ ] No credentials, personal secrets, or unnecessary personal data are included.
- [ ] Markdown renders correctly on desktop and mobile.
- [ ] Claims are accurate and can be explained in an interview.
- [ ] Review the README after major project or skill changes.

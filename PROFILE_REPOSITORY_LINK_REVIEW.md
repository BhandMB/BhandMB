# Profile Repository Link Review Checklist

Use this checklist when maintaining the GitHub profile README.

- [ ] Each featured repository link points to the intended public repository.
- [ ] Project summaries describe implemented functionality accurately.
- [ ] Technology lists reflect dependencies and code that are actually present.
- [ ] Build and run instructions have been tested or clearly marked unverified.
- [ ] Screenshots and demo links load correctly.
- [ ] No credentials, tokens, personal data, or local machine paths are included.
- [ ] Links to inactive or archived projects are labeled appropriately.
- [ ] Contact and professional profile links are current.

Review the README in rendered form after making changes.

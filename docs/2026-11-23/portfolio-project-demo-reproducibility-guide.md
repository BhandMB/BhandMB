# Portfolio Project Demo Reproducibility Guide

Date: 2026-11-23

## Purpose
Help reviewers reproduce a project demo from a clean checkout.

## Required setup information
Document supported operating systems, language and runtime versions, build tools, database requirements, environment variables, seed data, and startup commands. Provide safe example configuration without real credentials.

## Demo preparation
Use a dedicated demo dataset and accounts with clearly stated permissions. Explain how to reset the environment and how to avoid exposing personal or production data in recordings.

## Evidence
Record the commit or release identifier used for the demo. Ensure screenshots, API examples, and recorded behavior correspond to that version.

## Review checklist
- [ ] Clean-clone setup is documented.
- [ ] Dependencies and versions are explicit.
- [ ] Secrets are excluded.
- [ ] Demo data can be reset.
- [ ] Known limitations are disclosed.
- [ ] Demo evidence maps to a specific revision.

## Scope
Reproducibility guide only; no project was installed or executed as part of this commit.

# Java Backend Skills Evidence Map

**Date:** 2026-10-29  
**Purpose:** Connect resume skills to concrete, explainable portfolio evidence.

| Skill area | Evidence to prepare | Interview explanation |
|---|---|---|
| Core Java and OOP | A class/model and its responsibilities | Explain encapsulation and one design choice |
| Spring Boot REST APIs | Controller and endpoint example | Trace a request through the application |
| SQL and persistence | Entity mapping, repository query, or schema | Explain relationships and a useful constraint |
| Validation and error handling | DTO constraints and exception mapping | Walk through an invalid request |
| Spring Security/RBAC | Security configuration and permission test, if implemented | Explain authentication versus authorization |
| Testing | Real test class and recent execution result | Explain what the assertion protects against |
| Git and CI | Workflow configuration and commit history | Describe how a change is checked |
| Docker, if implemented | Dockerfile/Compose configuration and run evidence | Explain configuration and service dependencies |

## Rules for using this map

- Link only to evidence that exists in the repository.
- Mark planned or learning-only skills honestly.
- Do not imply a test passed without a recorded run.
- Use the map to identify the next demonstrable improvement, not to inflate a resume.

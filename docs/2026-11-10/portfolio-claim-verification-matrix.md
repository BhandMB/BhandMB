# Portfolio Claim Verification Matrix

> Created: 2026-11-10

Create an evidence matrix for resume and GitHub claims: technology actually used, implemented features, tests actually executed, deployment status, screenshots, and known limitations. Mark unverified statements for review before using them in job applications.

## Review requirements

- Inspect the current implementation before describing any item as an existing capability.
- Add concrete test inputs and expected outcomes before executing tests.
- Record actual test commands, results, and environment only after running them.
- Track unresolved business rules as open questions.

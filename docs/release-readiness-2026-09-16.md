# Portfolio Release Readiness — 2026-09-16

Before presenting a project publicly, verify that the repository explains its purpose, setup, test commands, supported runtime, and current limitations.

## Review checklist
- README setup steps work from a clean clone.
- Examples match the current API or UI behavior.
- Screenshots and links point to active resources.
- Test and build commands are documented.
- Known limitations are stated clearly.

## Evidence standard
Prefer repository evidence—source files, tests, CI runs, and reproducible commands—over vague technology claims.

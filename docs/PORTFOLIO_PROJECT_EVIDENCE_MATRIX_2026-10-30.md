# Portfolio Project Evidence Matrix
Date: 2026-10-30

Connect each resume skill claim to concrete repository evidence.

| Skill | Evidence to verify |
|---|---|
| Java and OOP | Domain classes, service logic, focused tests |
| Spring Boot | Configuration, controllers, services |
| REST APIs | Endpoint definitions and examples |
| SQL / MySQL | Schema, migrations, repository queries |
| Spring Security / RBAC | Security config and authorization tests |
| JPA / Hibernate | Entity mappings and persistence tests |
| OpenAPI | Specification or Swagger UI |
| Testing | Test sources and recorded execution |
| Docker | Dockerfile, compose file, run instructions |

Do not list a technology merely because it appears in a plan. Confirm use in code and link to specific evidence before using the claim in a resume.

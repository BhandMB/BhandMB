# GitHub Profile Maintenance Checklist

Date: 2026-11-03

## Profile overview
- [ ] Keep the introduction concise and aligned with current target roles.
- [ ] List skills that can be demonstrated in a technical discussion.
- [ ] Pin the strongest, maintained projects.
- [ ] Ensure project descriptions explain the problem, stack, and key features.
- [ ] Remove stale claims and broken links.

## Repository quality
- [ ] README includes setup steps and required versions.
- [ ] Secrets, local databases, build output, and personal files are excluded.
- [ ] Screenshots represent the current application.
- [ ] Build and test instructions are reproducible.
- [ ] Known limitations are stated honestly.

## Job-search alignment
Prioritize the Java/Spring Boot backend portfolio and make the HRMS, API, and frontend repositories easy to navigate. Update the profile when project status changes; do not imply that planned features are already complete.

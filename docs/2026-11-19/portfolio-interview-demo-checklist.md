# Portfolio Interview Demo Checklist

## Before the interview
- [ ] Clone the project into a clean workspace.
- [ ] Follow the README setup steps without relying on undeclared local files.
- [ ] Confirm required runtime and database versions.
- [ ] Use disposable demo data and credentials.
- [ ] Run the documented tests and record the actual result.
- [ ] Prepare a short explanation of architecture and trade-offs.

## During the demo
- [ ] Explain the user problem and main workflow.
- [ ] Demonstrate one meaningful validation or authorization boundary.
- [ ] Show the API or data model where relevant.
- [ ] Explain one defect or limitation honestly and how it could be improved.
- [ ] Avoid exposing secrets, personal data, or local machine paths.

## After the demo
Record questions that were difficult to answer and turn them into focused learning tasks. Keep the demo script aligned with the current code rather than memorizing outdated behavior.

# GitHub Profile Project Link Audit

## Objective
Keep the profile README useful to recruiters by making its project links accurate and easy to verify.

## Review steps
- Confirm each linked repository exists and is public when intended.
- Check that the repository name and description match its actual purpose.
- Ensure the README setup instructions reflect the current project structure.
- Remove stale demo links and broken badges.
- Prefer a small set of strong projects with clear evidence over a long uncurated list.
- Confirm screenshots and demo links point to the correct project version.

## Technical claim review
For every listed technology or feature, identify where it appears in the repository and how it can be demonstrated. Separate planned capabilities from implemented ones.

## Maintenance cadence
Recheck links after repository renames, default-branch changes, or major README updates. Record the review date and unresolved items; do not imply an audit passed until the links have been checked.

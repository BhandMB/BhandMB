# Portfolio README Quality Gate

## Required sections
- Clear project purpose and feature summary.
- Technology stack that matches the actual implementation.
- Prerequisites and reproducible setup instructions.
- Configuration guidance using placeholders, never real secrets.
- Verified test commands and representative screenshots where useful.
- Known limitations and contribution or license information where applicable.

## Review rule
Run setup instructions from a clean checkout before claiming they work. Remove unsupported feature claims and keep planned enhancements clearly separated from implemented functionality.

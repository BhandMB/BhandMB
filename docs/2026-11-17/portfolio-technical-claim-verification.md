# Portfolio Technical Claim Verification

## Review method
For each public skill or project claim, identify the exact implementation, configuration, test, or documentation evidence that supports it.

## Claim categories
- Implemented and manually verified.
- Covered by automated tests.
- Configured but not exercised in a real environment.
- Planned or currently learning.

## Quality rules
Do not describe a planned feature as complete, a test plan as a passing test suite, or a local setup as a production deployment. Recheck claims before updating a resume, profile, or project description.

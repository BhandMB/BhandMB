# Portfolio Project Evidence Index

## Purpose
Keep public project claims aligned with evidence available in the repositories.

## Evidence to maintain
- Concise project overview and architecture description.
- Setup instructions that work from a clean checkout.
- Representative API examples and screenshots where applicable.
- Tests that can be run locally or in CI, with truthful status.
- Known limitations and future improvements.

For each resume or profile claim, identify the repository file, implementation, or test that supports it. Label planned work as planned rather than completed. Review this index whenever a project changes materially or a resume bullet is updated.

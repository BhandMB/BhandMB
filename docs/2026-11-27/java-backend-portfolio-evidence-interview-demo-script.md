# Java backend portfolio evidence and interview demo script

## Purpose
Keep portfolio claims aligned with implementation and make demonstrations reproducible for Java backend interviews.

## Evidence map
For each claim, link to a concrete artifact:
- Java/OOP: domain classes and service logic.
- Spring Boot: configuration and controller/service structure.
- REST: endpoint examples and status/error behavior.
- SQL/MySQL: schema, relationships, constraints, representative queries.
- JPA/Hibernate: entity mappings and repository usage.
- Spring Security: authentication, role checks, negative authorization tests.
- Testing: named unit/integration tests and exact command.
- Docker/CI: actual configuration and successful workflow evidence, if present.

## Five-minute demo
1. State the problem and intended users.
2. Show architecture and data flow.
3. Demonstrate one successful workflow.
4. Demonstrate authorization denial or validation failure.
5. Explain one trade-off and one known limitation.
6. Show clean-checkout setup and test commands.

## Accuracy gate
Do not claim production deployment, microservices, Kafka, comprehensive test coverage, or CI success unless repository evidence supports it. Record Java/Spring versions and prerequisites exactly as implemented.

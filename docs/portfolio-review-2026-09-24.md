# Portfolio Review — 2026-09-24

## Contribution quality gates

- Every repository change should improve code, tests, documentation, configuration, or maintainability.
- Prefer small, reviewable commits with a clear purpose.
- Keep README claims aligned with the current implementation.
- Record validation steps for changes that affect runtime behavior.

## Review focus

- Java/Spring Boot backend evidence in the HRMS project.
- API correctness and negative-path coverage in library projects.
- User-flow reliability in mobile and desktop applications.
- Safe, reproducible local setup instructions.

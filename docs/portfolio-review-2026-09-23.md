# Portfolio Review — 2026-09-23

## Review focus
- Keep project descriptions tied to concrete implementation evidence.
- Prefer measurable outcomes over generic technology lists.
- Confirm each repository has a clear run path and test story.

## Evidence checklist
- [ ] README explains purpose, stack, setup, and verification.
- [ ] Recent commits improve code, tests, documentation, or configuration.
- [ ] Screenshots and links are current.
- [ ] Security-sensitive details are excluded from public files.
